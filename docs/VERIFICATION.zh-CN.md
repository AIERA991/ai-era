# 验证记录

验证日期：2026-09-07。

## 运行环境

Solidity 0.8.30，EVM Paris，优化 200 次，OpenZeppelin Contracts 5.4.0；Hardhat 3.15.0 内存链，链 ID 1337；ethers 6.17.0。编译产物可通过 `npm run compile` 重建，依赖由 package-lock.json 锁定。

## 已验证项目：17 项测试全部通过

11 项合约测试通过：固定总量及精确分配、无效部署地址、余额和授权限制、开发者锁仓边界与分期释放、交付/验收权限、重复结算防护、未交付退款、验收超时付款、仲裁权限与金额边界、仲裁超时退款、无效任务与失败存款、多个任务的资金隔离。部分测试覆盖多个相关行为。

模型接口另有 2 项测试：请求模型和提示词、精确 JSON 哈希；缺失配置、错误任务、服务失败及未完成响应的拒绝。测试使用模拟推理响应，不代表真实模型已经运行。

新增 4 项自动结算测试：真实重算小型固定分类器并立即支付、错误模型/输入/输出与非指定提交者拒绝、逾期退款与重复结算限制、负数及 int64 边界计算。此分类器为演示，不是经训练的商业 AI 模型，也不提供零知识或隐私保护。

本地端到端演示执行：部署代币与任务合约 → 模拟客户获得 100 AERA → 托管 25 AERA → 服务方提交固定示例结果 → 客户批准 → 服务方获得 25 AERA，客户剩余 75 AERA。演示后内存链关闭。
