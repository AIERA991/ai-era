# AI Era：V1 独立交易与退出日常运营

当前选择：保留已经部署的 V1，暂停 V2。目标是创始人不在线时，已经持有测试 AERA 的参与者仍能交易，而不是承诺没有任何人参与。

## 已完成

新增 `scripts/v1-transactions.mjs`：本地离线读取 JSON，生成 Sepolia 未签名交易，无网站、模型 API、项目方密钥依赖；不会连接网络、签名或广播。安装项目依赖后运行：

```sh
node scripts/v1-transactions.mjs request.json
```

固定目标：Sepolia（chainId 11155111），AERA `0x03D09526AE4FB71d8C3b233D2B165Ff4fD2B6320`，托管 `0x9D479C59A5AC4d242A49c9E1779d6CC18b1d87E2`。不是 ETH/USDT 商业收款入口，也不支持主网。

例如客户授权 10 枚测试 AERA：

```json
{
  "action": "approve",
  "from": "0x1111111111111111111111111111111111111111",
  "amount": "10"
}
```

替换 from 为自己的公开地址。输出为未签名交易对象，供支持自定义合约调用的钱包或开发工具使用；不是钱包可普遍导入的文件格式。签名前须核对链、目标、解码后的方法及参数，并按最新链上状态模拟。离线工具不能检查余额、授权、角色、任务状态或当前期限。不要将不理解的 calldata 直接签名。

所有请求包含 `action`、`from`；金额使用 AERA 十进制字符串，最多 8 位小数，任务编号使用正整数字符串。

| action | 其他字段 | 谁操作 |
|---|---|---|
| approve | amount（也可填 0 撤销授权） | 客户；spender 固定为托管合约 |
| createTask | provider、arbiter、amount、deliveryDeadline、specificationHash | 客户；三个地址必须不同 |
| submitResult | id、resultHash | 约定服务方 |
| approveResult | id | 客户 |
| dispute | id | 客户；交付后 7 天内 |
| resolve | id、providerAmount | 约定仲裁人；争议后 14 天内 |
| claimAfterReview | id | 任何人；验收期结束后付给原服务方 |
| refundUndelivered | id | 任何人；交付期结束后退给原客户 |
| refundUnresolved | id | 任何人；仲裁期结束后退给原客户 |

创建任务的 deliveryDeadline 是 Unix 秒数，必须晚于执行区块时间且不超过其后 90 天。specificationHash 和 resultHash 是双方保存的原始文件精确字节的 Keccak-256，不是文件名或文字描述。执行 `scripts/ai-worker.mjs` 可生成示例文件与哈希，实际服务可以使用双方同意的其他 AI。

## 独立交易流程

1. 客户自行找到服务方，双方约定价格、交付期限、文件格式、验收条件及独立仲裁人。现有工具没有撮合或公开订单列表。
2. 客户准备测试 AERA 和 Sepolia ETH，先核对现有 allowance，再授权本次确切金额。若已有非零授权需更改，先撤销并确认，再设置新额度。
3. 客户调用 createTask。以成功交易回执中的 TaskCreated 事件取得实际任务编号；不要预先猜测 nextTaskId。
4. 服务方通过双方约定的渠道交付文件并调用 submitResult；客户核对文件哈希与质量后验收或提出争议。
5. 按表中角色执行结算。超时不是自动发送交易，参与者或第三方需要发起并支付 Gas，资金去向由合约固定。

## 验证结果

运行 `node --test test/v1-independent.test.mjs`：2 项测试通过。内存链初始分配后，客户、服务方、仲裁人及第三方触发者完成五条结算路径，全程没有使用创始人或储备钱包签名，没有调用网站或模型服务。

客户最初 100 枚，五笔各 10 枚任务结算后客户 77 枚、服务方 23 枚、托管余额及记账余额均为零。未经授权的第三方验收和仲裁被拒绝。该验证不等于审计，也不是公开网络实测或上线记录。

## 仍然存在的依赖

- V1 仲裁人有权决定其被指定任务的分账，不是全局管理员。仲裁人失联后全部退给客户，对服务方不利，必须在接单前知悉。
- 原始文件须由参与者保存；链上哈希不能证明质量或保证数据永远可用，地址和金额公开。
- 当前网站访问受限；网站、存储及 DeepSeek 服务需要运营和费用。独立工具只能绕开这些入口，不能使它们自动去中心化。
- 95% 初始代币由储备钱包控制，当前没有无需许可的挖矿或公开领取机制。独立结算不等于独立发行。
- 开发者 5% 锁仓不产生自动收入；合约没有向创始人自动收取服务费。商业 ETH/USDT 收款与这里的测试币结算分开。

下一阶段若要开放市场，应先解决公开访问、第三方可自行部署的入口、订单发现与长期文件可用性，再开展公开测试。现有代码没有因此升级、重新发行或迁移资金。本次发布的是工具源码、测试和文档；不是网站功能更新、主网发行或真实收款开通。
