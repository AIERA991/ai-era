# AI Era · AERA

连接 AI 服务与日常交易的结算协议原型。**V1 已部署到 Sepolia 测试网；没有主网发行。当前保留 V1、暂停 V2，优化不依赖创始人批准的交易流程。**

## 独立交易工具

新增 [V1 独立交易与退出日常运营说明](docs/V1-INDEPENDENT.zh-CN.md)。客户、服务方和事先选定的仲裁人可自行结算；无需项目网站、DeepSeek API 或创始人钱包批准。

`scripts/v1-transactions.mjs` 读取 JSON，离线生成 Sepolia 未签名交易；不持有私钥、不广播交易。支持授权、创建任务、提交结果、验收付款、争议、仲裁和三种超时结算。

本地独立参与者测试通过五条路径：验收付款、未交付退款、验收超时付款、仲裁分账、仲裁超时退款。测试文件为 `test/v1-independent.test.mjs`，不代表独立安全审计或公开网络实测。

## 供给与交易规则

- 固定总量 21,000,000 AERA，8 位小数。社区 65%、生态 20%、流动性储备 10%、开发者 5%。
- 开发者 1,050,000 枚锁定 365 天，再按秒线性释放 1,460 天。任何人可触发释放，但只能付给指定受益人。
- 其余 95% 仍由初始储备钱包掌控，没有公开挖矿或无需许可的领取机制。这不是去中心化发行。
- 代币没有后续增发、管理员改余额、暂停、黑名单、转账税或升级入口。稀缺不保证价格、需求、流动性或收益。
- 客户与服务方自行约定价格。任务报酬来自客户已有代币，不来自增发；合约没有向创始人自动收取服务费。

客户创建任务前，服务方应在线下同意任务条款和仲裁人。最长交付期限 90 天；交付后 7 天验收；争议后仲裁人有 14 天分账。无交付或仲裁超时退客户；验收期内无争议则可触发付款给服务方。仲裁超时全额退款偏向客户，服务方须事先知悉。

任何人可发起已到期的超时操作，但需支付 Gas，且不能改变收款人。“创始人不参与”不等于无需交付、验收、仲裁或交易触发者。

## 本地运行

安装 Node.js 22.13+ 或 24 LTS，在项目目录运行：

```sh
npm ci --ignore-scripts
npm run compile
node --test test/v1-independent.test.mjs
npm test
node scripts/v1-transactions.mjs request.json
```

request.json 字段及签名前的核对步骤见[工具说明](docs/V1-INDEPENDENT.zh-CN.md)。金额使用最多 8 位小数的字符串，任务编号从成功交易的 TaskCreated 事件读取。

Solidity 0.8.30，优化 200 次，EVM Paris；OpenZeppelin Contracts 5.4.0、ethers 6.17.0、Hardhat 3.15.0。锁文件随仓库提供。

`npm run demo` 在内存链运行固定示例；`npm run agent` 通过 Ollama 生成 AI 文件与 Keccak-256 哈希。文件需双方保存，链上哈希不证明内容质量或真实模型身份。

## 当前边界

网站已有受限访问的工作台与测试流程，尚不是开放市场；商业 ETH/USDT 收款仍为沙盒，不能当作真实充值入口。独立工具可绕开项目网站，但不能保证模型服务、文件存储和第三方基础设施永久可用。

没有独立安全审计、隐私交易、抗量子账户、公开撮合、去中心化储备或主网发行。不存在“绝对无法破解”的保证。已部署合约不可原地升级，误转入合约的非任务资产可能无法取回。

[商家 AI 服务](docs/MERCHANT-AI-SERVICES.zh-CN.md)和[日常交易设计](docs/EVERYDAY-TRANSACTIONS.zh-CN.md)为产品设计背景。仓库内 V2、小模型自动验证及其演示属于历史研究，已经暂停，不是当前发行计划。项目未与 TRON、交易所或模型厂商建立合作关系。
